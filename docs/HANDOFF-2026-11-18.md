## What is on main now

Everything below passed 93 backend tests (Python 3.11 exact pins and 3.13 unpinned), a frontend build and `docker compose config`, and the approval-PIN code passed an independent security re-review. Nothing here has run on a phone, on Victor's Mac, or against a real Postgres.

- **Approval PIN** (env `APPROVAL_PIN`, header `X-Approval-Pin`, 8+ characters): required on `POST /tasks/{id}/approve`, `POST /control/resume`, `POST /echelon/resume`. Not on `POST /control/freeze`. 5 wrong PINs lock approvals and resume for 15 minutes (in-memory counter; a backend restart clears it). - **Ops** (`scripts/ops/`, `docs/`): nightly backup, restore drill (passed against a real Postgres 16 without pgvector, through a stand-in `docker`), launchd example files, always-on guide, Tailscale ACL. Compose requires `APPROVAL_PIN` and restarts containers.
